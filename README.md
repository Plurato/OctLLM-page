# OctLLM Project Page

The project website for **Octrees as an Explicit 3D Language**, featuring interactive 3D results, videos, and an overview of the method.

A static HTML/CSS/JavaScript site with no build step. Preview locally with `python3 -m http.server 4173 --bind 127.0.0.1`, then open [localhost:4173](http://localhost:4173).
